# Speechka — Лендинг онлайн-платформы

Современный лендинг для онлайн-платформы "Speechka" — инновационного решения для первичного анализа речи и коррекции у детей 4-12 лет.

## 🎯 О проекте

Лендинг создан для привлечения родителей, которые замечают у своих детей проблемы с речью (картавость, шепелявость) и ищут удобное решение для домашних занятий.

### Ключевые особенности:
- **Современный дизайн** с пастельной цветовой палитрой
- **Адаптивная верстка** для всех устройств
- **Интерактивные элементы** с плавными анимациями
- **SEO-оптимизация** для поисковых систем
- **Высокая скорость загрузки**

## 🎨 Дизайн

### Цветовая палитра:
- **Основные цвета**: Пастельные голубой (#E3F2FD) и мятно-зеленый (#E8F5E8)
- **Акцентные цвета**: Коралловый (#FF6B6B) и оранжевый (#FF8E53)
- **Текст**: Темно-серый (#2C3E50) и светло-серый (#7F8C8D)

### Шрифты:
- **Основной**: Inter (Google Fonts)
- **Fallback**: Системные шрифты

## 🚀 Быстрый старт

### Требования:
- Веб-сервер (Apache, Nginx) или локальный сервер
- Современный браузер с поддержкой ES6+

### Установка:

1. **Клонируйте или скачайте файлы проекта**
2. **Откройте `index.html` в браузере** или разместите на веб-сервере
3. **Настройте ссылки на онлайн-платформу**

### Настройка:

#### 1. Замените ссылки на онлайн-платформу
В файле `index.html` проверьте, что кнопки ведут на онлайн-платформу:

```html
<a href="https://speechka-platform.ru/" class="cta-button" target="_blank">
```

#### 2. Настройте мета-теги
Обновите мета-теги в `<head>` для вашего домена:

```html
<meta property="og:url" content="https://your-domain.com">
```

#### 3. Добавьте аналитику (опционально)
В файл `script.js` добавьте код для Google Analytics или других систем аналитики.

## 🔧 Кастомизация

### Изменение цветов:
Отредактируйте CSS-переменные в файле `styles.css`:

```css
:root {
    --primary-blue: #E3F2FD;
    --primary-mint: #E8F5E8;
    --accent-coral: #FF6B6B;
    --accent-orange: #FF8E53;
    /* ... */
}
```

### Добавление новых секций:
1. Добавьте HTML разметку в `index.html`
2. Создайте соответствующие стили в `styles.css`
3. При необходимости добавьте JavaScript функциональность

### Изменение контента:
- **Тексты**: Отредактируйте содержимое в `index.html`
- **Изображения**: Замените ссылки на изображения
- **Цены**: Обновите тарифы в секции pricing
